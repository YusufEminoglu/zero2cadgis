about=An advanced CAD and GIS dataset converter utility for the PlanX ecosystem, with native & ODA-assisted support for AutoCAD DWG (*.dwg) and DXF drawings, Netcad NCZ/NCA, KML, KMZ, GML, GeoJSON, delimited CSV/TSV text with automatic X/Y or WKT geometry detection, SpatiaLite/SQLite, GPX, DGN, and GDB formats directly, with drag-and-drop loading, pre-conversion layer preview and selection, CAD collinear simplification, coordinate transformation, automatic labeling, database joins, remembered import and export folders across sessions, a fast Batch Spatial Extent Filter to scan hundreds of drawings in seconds, and direct Web Map Tiles (MBTiles / TMS / XYZ) raster pyramid export with automated Web Mercator reprojection. Online User Manual & Documentation: https://geophilo.com/zero2cadgis/ | If you find this plugin helpful, please consider starring the repository on GitLab (https://gitlab.com/geophilo1/zero2cadgis)!
